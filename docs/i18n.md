# i18n

Español hoy, estructura lista para más idiomas.

- `src/lib/i18n/es.ts`: **todo** el texto visible vive aquí. Nada de
  strings inline en componentes.
- `src/lib/i18n/index.ts`: store `locale` + derivado `t`. Cambiar de
  idioma es añadir un catálogo y conmutar `locale`.
- Convenciones (skill frontend-design): voz del usuario final, verbos en
  activo, minúsculas de frase, cada texto con un solo trabajo; los vacíos
  invitan a actuar, los errores dicen qué pasó y cómo seguir.
- HTML raíz en `lang="es"`; fechas con `toLocaleDateString('es-CO', …)`.
